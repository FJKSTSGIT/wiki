# Admin UI Parts（ゲーム管理ツール UI 部品カタログ）

ゲーム運営向け管理ツールの **部品単位** のサンプル集です。Nuxt 4 + Nuxt UI 4 の標準部品を組み合わせて作っています。
`admin-console/`（画面モック）とは別のプロジェクトで、部品ごとに動くデモ・使い方のコード・Props 一覧を確認できます。

```bash
cd ui-parts
npm install
npm run dev              # http://localhost:3000
npm run generate:share   # 任意のパスに置ける静的ファイルを出力（.output/public）
```

## 収録内容

| ページ | 内容 | ファイル |
| --- | --- | --- |
| パターン一覧 | ゲーム管理ツールでよく使う画面・機能 70 件を 12 分類で一覧化。チェックで選択 → メニュー構成のプレビュー・テキストでコピー | `pages/patterns.vue`, `utils/patterns.ts` |
| サイドメニュー | 折りたたみ・スマホ用スライドメニュー・権限による項目の出し分け・バッジ・グループ | `components/parts/SideMenu.vue` |
| 固定ヘッダー（環境表示） | 本番 / ステージング / 開発 / ローカルを色ラインとバッジで常時表示。本番は注意バナー | `components/parts/EnvHeader.vue`, `utils/environments.ts` |
| 権限による表示切替 | 非表示 / 操作不可 / 伏せ字 の 3 通り。役割の切替で確認 | `components/parts/AccessGuard.vue`, `composables/useAccess.ts`, `utils/access.ts` |
| お知らせ設定 | ゲーム内お知らせの作成（種別・期間・対象・表示方法・プッシュ通知）、入力チェック、ゲーム内表示プレビュー | `components/parts/NoticeSettings.vue`, `NoticePreview.vue`, `utils/notice.ts` |

このカタログ自体も `SideMenu` と `EnvHeader` で作られています。画面上部の役割切替で「閲覧のみ」などにすると、左メニュー下段の項目が変わります。

## パターン一覧の分類

共通基盤 / ダッシュボード・分析 / プレイヤー（ユーザー情報） / マスタデータ / 抽選（ガチャ） / イベント・運営施策 / 配布・報酬 / お知らせ・告知 / 課金・ストア / カスタマーサポート / 運用・システム / 不正対策

各パターンに「ほぼ必須 / 推奨 / 必要に応じて」の目安と、主に使う UI 部品を付けています。
項目を増やすときは `utils/patterns.ts` に追記するだけで画面に反映されます。

## 仮定

- 「お知らせ設定」は **プレイヤー向けゲーム内お知らせの作成・配信設定** と解釈しました（スタッフ向けの通知設定ではない）
- 権限・役割はサンプル定義です。本番ではログイン時に API から受け取った権限一覧を `useAccess` に入れます
- 画面での出し分けは見た目の制御のみで、実際の可否判定はサーバー側でも必要です
